# Auslieferungsprüfer

Prüft, was eine Internetseite **wirklich** ins Netz gibt, bevor sie online geht:
fremde Adressen, von denen sie ungefragt nachlädt, versehentlich mitgelieferte
Server-Dateien, offene Schlüssel und Personenbezug. Läuft im Browser, lädt
nichts hoch.

**Öffnen:** https://lausiklauskn-png.github.io/Auslieferung-Pruefer/

Eigenständige Fassung des Prüfers aus [PWA Toolpoint](https://pwa-toolpoint.de/auslieferungspruefer.html).
